# AcmeWorks Policy Knowledge Base

Every policy in this directory was authored for the fictional AcmeWorks demo.
The files are not adapted from an employer, customer, or private repository.

Each Markdown file has a small metadata header and `##` sections. The AI API
indexes sections independently so every answer can cite the exact authored
source. Additions should include an ID, title, audience, review date, and
specific operational language. Vague source text should not be compensated
for by model inference.
